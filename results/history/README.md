# Historical development analysis

These files preserve the earlier five-epoch BBC analysis (selected epoch 4,
seed 42). They are **not used by the current manuscript or default reproduction
commands**. The retained `analysis_bbc.pt` release asset is historical only.

The current Figures 3 and 4 use `main_bbc.pt` (selected epoch 17 from 20 epochs)
and `results/predictions/main_bbc.jsonl.gz`. Current case IDs and quartiles are
one directory above this one. Earlier source and provenance remain available
in Git history and `results/provenance.json`; no checkpoint has been deleted.
